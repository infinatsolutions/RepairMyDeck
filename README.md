# RepairMyDeck

RepairMyDeck is currently a scaffold for a 32-agent OpenClaw/Codex 3D game development organization. It is not a completed game, not a playable prototype, and not an activated OpenClaw runtime.

## Purpose

This repository is intended to hold the reviewable planning, governance, agent instructions, draft OpenClaw desired-state descriptors, validation scripts, Godot-ready folders, asset/license registries, and production documentation needed before game implementation begins.

## Current Status

- Scaffold phase only.
- No production OpenClaw activation has been performed.
- No real playable game content is included.
- No third-party assets are approved for commercial use.
- Future work must proceed card-by-card with safe, idempotent, non-destructive changes.

## Safety Model

All OpenClaw configuration created in this repository must remain draft-only until explicitly approved by Albert. Any destructive command, install/removal, network upload/download, credential handling, publishing action, release-candidate approval, license exception, or OpenClaw activation requires human approval.
